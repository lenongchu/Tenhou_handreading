## 二、专有名词（Terminology）

### 立直麻将 / 天凤

| 术语 | 英文 | 含义 |
|------|------|------|
| 立直 | Riichi | 宣告听牌，之后不能换牌 |
| 舍牌 | Discard | 玩家打出的牌 |
| 手切 | Tedashi | 从手牌打出（非摸切） |
| 摸切 | Tsumogiri | 摸牌后立即打出该牌 |
| 副露 | Call/Meld | 吃(chii)/碰(pon)/杠(kan) |
| 听牌 | Tenpai | 差一张即可和牌 |
| 向听 | Shanten | 距听牌差几手，0=听牌 |
| 宝牌 | Dora | 和牌时每张额外番数 |
| 赤五 | Red Five | 0m/0p/0s，替代 5m/5p/5s |
| 巡目 | Turn | 某玩家第几次出牌 |
| 本场 | Honba | 连庄次数 |
| 亲家/庄家 | Oya | 东家 |

### 牌符编码

| 概念 | 说明 |
|------|------|
| base | 0-36：1m=0..9m=8, 1p=9..9p=17, 1s=18..9s=26, 字牌 27-33, 赤五 34/35/36 |
| tile | 0-147：base*4（同种牌 4 张） |
| 牌符字符串 | 1m-9m, 1p-9p, 1s-9s；0m/0p/0s=赤五；1z-7z 或 东/南/西/北/白/发/中 |

### 舍牌模式语法

| 符号 | 含义 | 示例 |
|------|------|------|
| `-` | 舍牌分隔 | `3s-1s` |
| `*` | 任意数量摸切 | `3s-*-1s` |
| `t`/`f` | 必须摸切/手摸切皆可 | `3mt`, `3mf` |
| `@c:`/`@p:` | 吃/碰占位 | `4mc3m5m` |
| `@cd:` | 拆搭 | `@cd:1` |
| `z`/`zf`/`kf` | 字牌占位 | z=任意字牌, zf=自风, kf=客风 |

## `assets`（资源文件）

### `assets/3d-tile/`

3D 麻将牌渲染用的 PNG 图，牌名与文件名一一对应：

- **万子**：`Man1.png`–`Man9.png`、`Man5-Dora.png`
- **筒子**：`Pin1.png`–`Pin9.png`、`Pin5-Dora.png`
- **索子**：`Sou1.png`–`Sou9.png`、`Sou5-Dora.png`
- **字牌**：`Ton.png`, `Nan.png`, `Shaa.png`, `Pei.png`, `Haku.png`, `Hatsu.png`, `Chun.png`
- **其他**：`back.png`（牌背）、`unknown.png`、`base_*.png` 等

### `assets/riichi-mahjong-tiles/`

来自 [riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles) 的牌面素材（CC0）：

- `Regular/`：SVG 矢量图，用于高质量渲染
- `Export/Regular/`：PNG 位图，作为备选
