## 目录层级概览

```
Tenhou_handreading/
├── run.py                 # 主入口
├── src/                   # 核心源码（gui_app, live_analyzer, equivalent_variants 等）
├── data/                  # tenhou.db、query_archive.json
├── assets/                # tile-assets（牌面）、3d-tile
├── docs/                  # 技术文档
├── scripts/               # 调试脚本
├── tests/                 # 测试
├── .cursor/rules/         # 项目手册 tenhou-handreading-project.mdc
├── houou-logs/            # 牌谱下载工具（可为空）
└── tenhou-paifu-to-json-main/  # XML→JSON 转换
```

根目录脚本：`download_historical_data.py`, `convert_xml_to_tenhou6.py`, `clean_new_logs.py`, `clean_bye_logs.py` 等。

详见 **`.cursor/rules/tenhou-handreading-project.mdc`** 第五、六节。
