## 技术细节

### 判断规则
对局被删除的条件（所有条件必须同时满足）：
1. 存在 `<BYE who="N"/>` 标签
2. BYE 标签不在最后一个 INIT 标签之后（即不在最后一局）
3. 在该小局结束前，没有找到对应玩家的 `<UN nN="..."/>` 重连标签

### 性能优化
- 批量处理（每次1000条）
- 使用数据库事务
- VACUUM 压缩回收空间
