# 快速参考：数据质量管理

## 新用户（首次下载数据）

1. 在 GUI 中下载历史数据
2. 下载完成后运行清理脚本：
   ```bash
   py clean_new_logs.py
   ```
3. 开始使用应用进行查询

## 定期更新数据

每次下载新数据后：
```bash
py clean_new_logs.py
```

## 查看数据库状态

```bash
# 查看数据库统计信息
py check_db_status.py

# 试运行清理（不删除，只查看统计）
py clean_bye_logs.py

# 执行完整清理
py clean_bye_logs.py --execute
```

## 什么样的对局会被删除？

**仅删除**：玩家在非最后一局掉线且未重连的对局

**保留**：
- 所有玩家都正常打完的对局
- 玩家在最后一局提前离开的对局（正常行为）
- 玩家掉线后成功重连的对局
